# Publication dates

Dates use `YYYY.MM.` in the publication list. Month values are represented by semantic `<time datetime="YYYY-MM">` elements. Conference and journal entries appear first, followed by arXiv and other preprints at the bottom of the same Publications section, without a separate visible section heading. Each group is ordered newest first; when available, exact dates break ties within a month. No JavaScript is required.

Journal entries use the journal issue month. Conference entries use the conference/presentation month, not the earlier arXiv submission date. Public preprints use the first public posting month, not a later revision. A local draft entry awaiting public posting may use an author-specified manuscript month, recorded explicitly below. An upcoming conference date is not a claim that proceedings have already been published.
